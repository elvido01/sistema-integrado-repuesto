# Acuerdo operativo — Vault compartido entre agentes

Relacionado: [[target-ideal]] · [[Notas de Claude]] · [[Notas de Hermes]]

## Acuerdo
El vault compartido es la fuente de contexto de largo plazo para estrategia, decisiones, módulos, procesos y aprendizajes de MotoFlow y Repuestos Morla.

## Uso de Hermes
- Buscar primero en el vault antes de responder temas estratégicos o de producto.
- Citar la nota relacionada cuando aporte contexto a una decisión.
- Guardar en `agentes/hermes/` únicamente resúmenes y aprendizajes que sigan siendo útiles después de un mes.
- No escribir credenciales, datos personales de clientes, teléfonos, RNC ni información sensible.
- Mantener la base de datos como fuente de verdad para datos operativos actuales.

## Coordinación
Claude y Hermes leen las notas compartidas. Cada agente escribe solo en su carpeta, de modo que las decisiones y el conocimiento relevante permanezcan accesibles sin alterar notas de otros autores.
