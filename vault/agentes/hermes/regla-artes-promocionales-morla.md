# Regla obligatoria — artes promocionales de Repuestos Morla

- Toda pieza final debe generarse mediante la API de imágenes de OpenAI, calidad media. No entregar composiciones locales/manuales como arte final.
- Consultar primero el vault y la referencia visual aprobada; no reinterpretar ni cambiar su plantilla.
- Usar foto real del producto, logo original, datos vigentes de MotoFlow y zonas seguras de Story 9:16.
- Confirmar en la base precio, stock e imagen inmediatamente antes de generar; los precios pueden cambiar.
- Si la referencia visual exacta no está disponible, pedirla o recuperarla antes de generar; no sustituirla por un diseño genérico.
