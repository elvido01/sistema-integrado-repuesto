# Architecture Decision Records (ADRs)

Cada decisión arquitectónica o de negocio importante queda como un archivo `AAAA-MM-DD-titulo-corto.md` aquí.

## Formato

```markdown
# AAAA-MM-DD — Título corto

## Contexto
Qué problema teníamos. Restricciones, opciones consideradas.

## Decisión
Qué decidimos hacer y por qué.

## Consecuencias
Qué se gana, qué se pierde, qué queda por hacer.

## Referencias
- Issues, PRs, archivos clave
- Memoria/CLAUDE relacionados
```
